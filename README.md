# CI/CD Pipeline Project 🚀

## Overview
This project demonstrates an end-to-end CI/CD pipeline using Jenkins, Docker, and AWS EC2.

## Features
- Automated deployment using Jenkins
- Docker containerization
- Live web app with version tracking
- Deployment timestamp and request counter

## Tech Stack
- Node.js
- Docker
- Jenkins
- AWS EC2

## How It Works
1. Push code to GitHub
2. Webhook triggers Jenkins
3. Jenkins builds Docker image
4. App is deployed to EC2 automatically

## Output
Live application showing:
- Version
- Deployment time
- Request count
